          Real-time chat platform
          Team of 4
        

        
SOPChat

        

          

            
A Discord for the classroom

            
Servers, channels, private chats, file sharing and a members list, built for the apprentices at TEC. One PC hosts it, and everyone else just opens it in the browser.

          

          

            
Real-time and locked down

            
Messages arrive instantly over SignalR. Login uses JWT with refresh tokens, and the server re-checks membership and rate-limits every user, so nobody can read a channel they are not in.

          

          

            
Clean architecture, one Docker image

            
Clean layers (Domain, Application, Infrastructure, API), EF Core on SQL Server, an admin dashboard and a daily curriculum quiz with 1,000 questions. Ships as one Docker image.

          

        

        

        
C# · ASP.NET Core · SignalR · Angular · EF Core · SQL Server · Docker

          Preparedness app · in development
          Team project
        

        
Nabolys

        

          

            
Ready for the first three days

            
Nabolys helps a household get through the first three days of a crisis: stock with best-before dates, a three-day list from the authorities' advice, a family plan and an "I am OK" check-in.

          

          

            
Works when the network is down

            
Phones close to each other pass messages on over Bluetooth, through native modules in Kotlin and Swift. What the family shares is encrypted on the phone, so the server cannot read it.

          

          

            
Built with Yasir and Jawad

            
A team project with Yasir Teksen and Jawad Qayyum: an ASP.NET Core API on .NET 10 with Azure SQL and Entra ID, infrastructure in Bicep, CI in GitHub Actions and more than 2,300 automated tests.

          

        

        

        
C# · .NET 10 · SignalR · Azure SQL · Bicep · React Native · Kotlin · Swift

          Price calculator · school assignment
        
    
        
    TaxaPris
    
        
    
          
    
            
    A price in seconds
    
            
    Built for a taxi company's customer service. Pick two addresses, and the route, distance and driving time are filled in from OpenStreetMap. Out comes a full price breakdown with every line and a total.
    
          
    
          
    
            
    Business rules as code
    
            
    Day, evening and holiday tariffs, two vehicle types and six surcharges, from the airport to the Great Belt and Øresund bridges. Each surcharge is its own class, so a new rule never touches the old ones.
    
          
    
          
    
            
    Locked down by tests
    
            
    xUnit tests the pricing engine and Vitest tests the Angular app. One test reads the real tariff file and checks the company's official control price, so a wrong tariff fails the build.
    
          
    
        
    
        
    
        
    .NET 8 · ASP.NET Core Web API · Angular · Signals · xUnit · Vitest · OSRM
